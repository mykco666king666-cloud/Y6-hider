A LITTLE MORE PEACE OF MIND

Privacy that feels personal.

Useful tools for keeping sensitive media private—without pretending privacy is magic.

Encrypted media storage

Imported copies are encrypted in private app storage using AES-256. The app uses Android Keystore to wrap its vault data key when available.

01

PIN or biometrics

Unlock with your security PIN, or use supported Android biometrics when enabled on your device. Recovery keys offer another route back in.

02

Albums that make sense

Organize your private photos and videos into albums. Search, filter, sort, and select media inside your vault.

03

Password-protected backups

Create or restore .ovbackup archives protected with PBKDF2 and AES-256-GCM. Keep the password safe: it is needed to decrypt the archive.

04

You choose what happens to originals

Importing creates encrypted copies. Removing an original from the public gallery is a separate, optional action that uses Android's system confirmation.

05

Storage & integrity tools

Review vault storage usage, clear temporary cache, and run a file integrity check that compares stored media against SHA-256 checksums.

06

Encryption details describe the current Android app implementation; device configuration and OS behavior can vary.

ABOUT THE APP

Built to keep your
private things private.

Gallery Hider is the website name for this Android app project. The Android app currently identifies itself as Obsidian Vault. It is built around a straightforward idea: private media should be stored and managed on your device, with clear controls for access and recovery.

The app's privacy screens describe an offline design. Features listed here reflect the current repository implementation; this website does not imply a third-party security audit or make absolute security guarantees.
